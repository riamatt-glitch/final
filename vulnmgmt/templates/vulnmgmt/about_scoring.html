How the Smart Priority Score is calculated

CVSS measures how severe a vulnerability is in general. The Smart Priority Score measures how urgent it is for this organisation. It treats CVSS as one input among several. Each factor is scaled to a value between 0 and 1 and multiplied by its weight. The weights add up to 100, so the score runs from 0 to 100.
